# 节拍工坊测试音乐

文件：`节拍测试曲-120BPM-第一拍2秒.wav`

这是一段专门用于检查节拍工坊的本地测试曲，不涉及版权音乐。

已知答案：

- BPM：120
- 拍号：4/4
- 前奏：2 秒
- 第一拍 Offset：2.000 秒
- 每拍间隔：0.500 秒
- 第一小节主拍：2.000、2.500、3.000、3.500 秒
- 后续小节第一拍：4.000、6.000、8.000 秒……

建议测试步骤：

1. 在节拍工坊加载 WAV 文件。
2. 选择“精简”，弱拍保留程度保持 45%。
3. 点击“分析音乐并生成节拍”。
4. BPM 应接近 120，Offset 应接近 2.000 秒。
5. 点击“从第一拍试听”，提示音应该与鼓点对齐。
6. 将 Offset 改成 2.100 秒并应用，应该能明显听到提示音晚了约 100ms。
7. 再把 Offset 改回 2.000 秒。

允许几十毫秒范围内的小误差，因为声音起音和分析窗口都不是无限精确的。如果 BPM 检测成 60 或 240，可以使用“减半/加倍”按钮修正。
